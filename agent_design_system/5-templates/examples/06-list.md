@user
다음 달에 이사하는데 뭐부터 준비하면 돼?

@assistant
이사 준비는 **2주 전 → 1주 전 → 당일** 순서로 나누면 빠뜨리는 일이 줄어요. 시기별로 할 일을 정리했어요.

### 2주 전

1. 이사 업체 견적 받기
2. 공과금 정산 · 이전 신청
   - 전기 · 가스 · 수도는 이사 당일 기준으로 신청
   - 인터넷은 이전 설치 날짜를 미리 잡기
3. 버릴 짐 정리하고 대형 폐기물 신고하기

### 1주 전

- 전입신고 일정 확인 (이사 후 14일 이내)
- 냉장고 비우기 시작
- 귀중품 · 서류는 따로 챙기기

당일에는 아래 항목만 확인하면 돼요. 이미 끝낸 일은 체크해 두었어요.

- [x] 이사 업체 계약
- [x] 인터넷 이전 신청
- [ ] 가스 철거 · 설치 시간 확인
- [ ] 새 집 사진 찍어 두기
