# 1-2. UI 원칙

채팅 화면을 만들 때 모든 규칙보다 앞서는 판단 기준입니다. 규칙끼리 부딪히거나 규칙에 없는 상황이면 이 원칙으로 판단합니다. 규칙은 [2-2. UI 규칙](../2-rules/2-2-ui.md)에 있습니다.

## 원칙

| ID | 원칙 | 뜻 |
| --- | --- | --- |
| P-UI-01 | **한 줄로 쌓는다** | 대화는 위에서 아래로만 쌓이고, 새 메시지는 항상 맨 아래에 붙는다. 가로로 나란히 놓이는 요소는 없다 |
| P-UI-02 | **요청은 상자, 응답은 본문** | 사용자 요청은 회색 말풍선, AI 응답은 배경 · 말풍선 · 이름 라벨 없이 화면 위에 바로 놓인다 |
| P-UI-03 | **간격은 위에만** | 블록 사이 거리 = gap 8 + 뒤 블록의 위 여백. 앞 블록은 아래 여백을 두지 않는다 |
| P-UI-04 | **값은 토큰으로** | 색 · 모서리 · 서체는 정해진 토큰만 쓴다. 새 값을 만들지 않는다 |
| P-UI-05 | **화면이 달라도 비율은 같다** | Mobile · Tablet은 늘어나고 Desktop은 720으로 고정한다. 요청 영역은 어디서나 1 : 3 |

## 미정

- P-UI-03 · P-UI-05가 값(gap 8, 720)을 직접 적음. 값은 4단계에만 두는 프로필 "값 표기"와 맞지 않음
