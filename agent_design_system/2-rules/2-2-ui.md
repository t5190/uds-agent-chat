# 2-2. UI 규칙

채팅 화면의 동작과 사용 기준을 정하는 규칙입니다. 값은 4단계 컴포넌트 문서에 있습니다. 원칙은 [1-2. UI 원칙](../1-principles/1-2-ui.md)에 있고, 강도는 [core 표준](../../standard/core/doc-standard.md)의 "규칙 표기"를 따릅니다.

| UI-MSG-10 | 필수 | 접힌 상태에서는 다섯째 줄 끝을 말줄임(…)으로 자르고, 말풍선 폭은 3fr을 채운다 | 긴 요청이 대화를 가리지 않게 | — |
| UI-MSG-11 | 필수 | 펼치면 전체 원문을 보여 주고 버튼 문구만 '접기'로 바꾼다(위치는 본문 아래 그대로) | 긴 요청이 대화를 가리지 않게 | — |

| UI-MSG-14 | 필수 | 전체보기 · 접기는 텍스트에만 적용하고 첨부 이미지 · 파일은 접지 않는다 | 긴 요청이 대화를 가리지 않게 | — |
| UI-MSG-15 | 금지 | AI 답변에 말풍선 · 아바타 · 이름 라벨을 붙이지 않는다. 화면 배경 위에 바로 놓는다. 작업 상태 심볼(UI-SYM)은 상태 표시라 대상이 아니다 | P-UI-02 | ✅ 배경 위 본문 · ❌ AI 말풍선 · 아바타 |

| UI-MSG-18 | 필수 | 응답 액션 줄 버튼은 복사 · 좋아요 · 싫어요 · 공유 · 다시 생성 순서로 둔다 | 버튼 순서 통일 | — |
