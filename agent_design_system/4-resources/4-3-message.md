# 4-3. 메시지

한 턴을 이루는 두 영역의 모양을 정합니다. **요청 영역**은 사용자가 보낸 메시지 말풍선, **응답 영역**은 AI 답변(마크다운)과 액션 줄입니다. 대화 전체 배치는 [3-1. 화면](../3-composition/3-1-page.md), 턴 안의 배치는 [3-2. 턴](../3-composition/3-2-turn.md)을 보세요.

- 상태: 응답 영역 부가 요소(작업 상태 줄 · 출처)는 초안
- 구현: 일부 지원(chat-ui.js가 말풍선 · 전체보기 · 액션 줄을 지원. 작업 상태 줄 · 출처는 스펙만)
- 규칙: [2-2 메시지](../2-rules/2-2-ui.md#메시지-ui-msg) UI-MSG-01 ~ 23

## 구조

### 요청 영역

말풍선은 본문 텍스트를 감싸는 회색 상자와, 그 아래 오른쪽에 붙는 액션 줄로 이루어집니다. 5줄을 넘으면 본문 아래에 전체보기 버튼이 들어갑니다.

```
.msg.user                       1fr : 3fr 그리드, 위 40
├─ (1fr 열은 비움)
├─ .col                         3fr 열, 오른쪽 정렬, 세로 gap 12
│  ├─ .attach                   첨부 (있을 때만) — 이미지 · 파일
│  └─ .bubble                   회색 상자
│     ├─ p                      본문
│     └─ .more                  전체보기 / 접기 (5줄 초과일 때만)
└─ .actions                     높이 40, 오른쪽 정렬 — 복사
```

| 요소 | 클래스 | 역할 |
| --- | --- | --- |
| 요청 영역 | `.msg.user` | 사용자가 보낸 메시지가 놓이는 곳 |
| 3fr 열 | `.col` | 첨부와 말풍선을 담는 열 |
| 첨부 | `.attach` | 이미지 · 첨부 파일 카드 묶음(있을 때만) |
| 말풍선 | `.bubble` | 텍스트만 담는 회색 상자 |
| 본문 | — | 말풍선 안 텍스트(`p`) |
| 전체보기 버튼 | `.more` | 5줄 초과 본문을 펼치고 접는 텍스트 버튼 |
| 액션 줄 | `.actions` | 복사 버튼 |

### 응답 영역

```
.msg.ai                         위 0, 전체 폭, 배경 · 말풍선 없음
├─ .content                     마크다운 블록 세로 스택 (gap 8)
│  ├─ .status                   작업 상태 표시 (선택) — 심볼(.symbol) + "12초 동안 작업함 ›"
│  ├─ p · h2 · ul · .tw …       답변 본문 — [4-4. 마크다운 요소](4-4-markdown.md)
│  └─ .sources                  출처 목록 (선택)
└─ .actions                     높이 40, 왼쪽 정렬 — 복사 · 좋아요 · 싫어요 · 공유 · 다시 생성
```

| 요소 | 클래스 | 역할 |
| --- | --- | --- |
| 응답 영역 | `.msg.ai` | AI 답변이 놓이는 곳 |
| 본문 | `.content` | 마크다운 블록 세로 스택([4-4. 마크다운 요소](4-4-markdown.md)) |
| 작업 상태 줄 | `.status` | 답변 맨 위 작업 시간 요약과 심볼(`.symbol`)(선택) |
| 출처 제목 | — | 답변 끝 "출처" 제목 |
| 출처 목록 | `.sources` | 번호 · 파비콘 · 링크 목록(선택) |
| 액션 줄 | `.actions` | 복사 · 좋아요 · 싫어요 · 공유 · 다시 생성 |

### 요청 영역

| 요소 | 속성 | 값 | 비고 |

| 말풍선 | 배경 · 모서리 | 배경 `color/container/base/higher` #E5E5E5 · radius 12 | 그림자 · 테두리 없음 |
| 말풍선 | 패딩 | 10 / 16 | 상하 10, 좌우 16 |
| 말풍선 | 최대 폭 | 3fr 열 폭(콘텐츠 폭 × 3/4). 짧으면 내용 폭, 길면 그 폭까지 채운 뒤 줄을 바꿈 | 1fr 열은 침범하지 않음 |

| 액션 줄 | 높이 · 아이콘 | 높이 40 · 아이콘 20 | 복사 버튼 |
| 액션 줄 | 호버 | 요청과 응답 모두 해당 영역에 호버하면 액션 아이콘이 나타남(키보드 포커스도 같음). 아이콘이 안 보여도 액션 줄(높이 40)은 자리를 지켜 아래 내용이 밀리지 않음. 호버가 없는 터치 화면에서는 항상 보임 | 항상 고정 |
| 전체보기 버튼 | 글자 | '전체보기' / '접기' · 14 Medium · #747474 | 텍스트 버튼. 밑줄 · 아이콘 없음 |

## 상태

| 상태 | 언제 | 바뀌는 것 |
| --- | --- | --- |
| 말풍선 기본 | 본문이 5줄 이하 | 전체보기 버튼 없음 |
| 말풍선 접힘 | 본문이 5줄 초과 | 본문 아래에 '전체보기' 버튼 |
| 말풍선 펼침 | 전체보기를 누른 뒤 | 버튼 글자가 '접기' |
| 작업 중 | 답변을 만드는 동안 | 작업 상태 줄에 생각 중 · 생각 끝 · 작업 중 심볼 표시([4-9. AI 심볼 · 모션](4-9-symbol.md)) |
| 작업 끝 | 작업이 끝났을 때 | 작업 상태 줄이 서서히 사라짐(UI-SYM-09) |

## 동작

1. 작업 상태 줄을 누름 → 작업 과정을 펼친다
2. 전체보기 버튼을 누름 → 본문을 펼치고 버튼이 '접기'로 바뀐다

## 반응형

| --- | --- | --- | --- |

## 미정

- 응답 영역의 작업 상태 줄 · 출처는 초안
- 스크림 높이가 이 문서는 140, [4-7. 입력창](4-7-input.md)은 158로 다름
- 맨 아래로 이동 버튼 배경이 이 문서와 [4-1. 디자인 토큰](4-1-tokens.md)은 `alpha/white-80`, 4-7은 `#FCFCFC`로 다름
- Mobile 3fr 열 폭이 이 문서는 272, [3-2. 턴](../3-composition/3-2-turn.md)은 271.5로 다름
- 말풍선을 접는 기준: 피그마(111-64801)는 5줄 초과 시 4번째 줄 끝에 말줄임표와 전체보기, 이 문서와 `lib/chat-ui.js`(`CLAMP_LINES = 5`)는 5줄 초과 시 말줄임표 없이 전체보기만 둠. 피그마의 "4번째 줄"이 맞는지 디자이너 확인 중
