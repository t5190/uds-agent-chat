# Working

응답을 만들거나 작업(도구 호출 · 리서치 포함)을 하는 동안 반복되는 상태 모션입니다. 작업이 끝나면 심볼과 시머 문구는 그룹으로 페이드 아웃하고 **완료 문구**가 심볼 자리로 이동해 남습니다. 완료 문구 옆 `>`로 작업한 내용을 펼쳐 볼 수 있습니다. 화면 구조와 표시 크기는 [4-9. AI 심볼 · 모션](../4-9-symbol.md)에 있습니다.

- 상태: 초안. 완료 문구 내용과 전달 방식, `>` 연출은 미정
- 규칙: [2-2 심볼](../../2-rules/2-2-ui.md#심볼-ui-sym) UI-SYM-05, UI-SYM-09, UI-SYM-18 ~ 19, UI-SYM-24, UI-SYM-27 ~ 29

## 구조

| 요소 | 클래스 | 역할 |
| --- | --- | --- |
| 작업 상태 심볼 | `.symbol.is-status` | `agent_working` 슬롯. 작업 완료 때 시머 문구와 함께 페이드 아웃 |
| 작업 상태 텍스트 | `.status-label` | 단계별 문구(길이 가변, `setStep()`으로 교체). 시머가 붙음 |
| 완료 문구 | `.status-label.is-complete-label` | 작업 완료 때 시머 문구 자리에서 나타나 심볼 자리로 이동하는 정적 글자 |
| 펼침 `>` | `.status-chevron` | 완료 문구 오른쪽. 눌렀을 때만 작업 내용을 펼침 |

## 배치

| 요소 | 기준 | 위치 · 정렬 |
| --- | --- | --- |
| 작업 상태 줄 | 응답 영역 | 맨 위 |
| 완료 문구 | 작업 상태 줄 | 안착 후 심볼이 있던 자리(왼쪽 끝) |
| 펼침 `>` | 완료 문구 | 문구 오른쪽 |

- 쓰는 곳: 대화 중 작업 상태 줄(첫 응답 ~ 완료), 도구 호출 · 리서치 단계
- 쓰지 않는 곳: 첫 응답 전(→ [Thinking](thinking.md)), 최초 진입 · 온보딩(→ [Signature](signature.md)), 생각 중에 바로 답이 나온 간단한 질문(완료 문구 없이 사라짐)

## 상태

| 상태 | 언제 | 바뀌는 것 |
| --- | --- | --- |
| 작업 중 | 생각 끝 재생 완료 | `agent_working`(3.84초 · 128프레임)을 0프레임으로 이어 재생하고 반복. 원 → 원 세 개 → 심볼 → 원, 시계 방향 회전. 단계가 바뀌어도 처음부터 다시 시작하지 않음 |
| 사라짐 | `finish()` 직후 0 ~ 240ms | 심볼과 시머 문구가 한 그룹으로 페이드 아웃(값은 [Text Shimmer](text-shimmer.md) "퇴장"). 사라지는 동안 회전과 하이라이트는 멈추지 않음 |
| 이동 | 0 ~ 240ms(임시, 사라짐과 동시) | 완료 문구가 시머 문구 자리에서 투명도 0 → 100%로 나타나며 심볼 자리(왼쪽 끝)로 이동. 작업 내용은 펼치지 않음 |
| 안착 | 240ms 이후 | 심볼과 시머 문구는 비움. 완료 문구가 심볼 자리에 정지하고 시머 없는 정적 글자. 오른쪽에 `>`가 접힌 상태로 표시 |

## 동작

1. 생각 끝 재생 완료 → `agent_working`을 0프레임으로 이어 재생. 심볼과 문구는 사라지지 않음. Working은 생각 끝에서만 시작하고 단독으로 0프레임부터 시작하지 않음
2. 문구 → 생각 끝 구간 0.45초에 교체 시작, 0.57초에 글자 교체. 사라짐 120ms + 나타남 120ms, 폭 240ms 전환
3. `setStep(문구)` → 문구만 교체. 심볼 모션과 시머는 처음부터 다시 시작하지 않음
4. `finish()` → 즉시 시작(한 주기가 3.84초라 기다리면 완료가 늦어 보임). 심볼 + 시머 문구가 240ms 그룹 페이드, 같은 시간에 완료 문구가 나타나며 왼쪽으로 이동
5. 완료 문구 이동 곡선 `cubic-bezier(0.4, 0, 0.2, 1)`(임시, 문구 교체와 같은 곡선). 이동 중에는 문구를 자르지 않음
6. 안착(240ms) 후 `onDone`을 1회 호출. 답변 본문 표시는 콜백 이후 앱이 처리
7. `>`를 누르면 작업한 내용을 아래로 펼치고 다시 누르면 접음. 안착 후에도 자동으로 펼치지 않음. 누르는 영역은 완료 문구 + 아이콘 전체(임시)
8. 작업 완료 중(0 ~ 240ms)에 `think()`가 오면 완료 처리를 취소하고 Thinking부터 새로 시작
9. 이전 답변의 완료 문구 · 아코디언은 그대로 남고, 새 질문은 새 작업 상태 줄에서 Thinking 시작
10. 탭 숨김 · 앱 백그라운드 → 정지, 복귀 시 이어서 재생. 숨겨진 동안 `finish()`가 오면 애니메이션 없이 바로 완료 상태(완료 문구 + `>`)로 둠
11. 잘못된 순서의 호출(작업 중이 아닐 때 `setStep()` 등)은 오류 없이 무시
12. 움직임 줄이기가 켜지면 정지 프레임. 작업 완료 때 심볼 · 시머는 크기 변화 없이 투명도만 바꾸고, 완료 문구는 이동 없이 심볼 자리에 바로 보임
13. 단계 문구 변경은 스크린리더가 읽지 않고 완료 시점에 완료 문구를 읽음. 잘린 문구의 전체 내용은 읽음. `>`는 버튼이고 펼침 · 접힘 상태를 알림(`aria-expanded`)

## 미정

- 완료 문구의 내용과 전달 방식(예: `finish()`에 완료 문구와 단계 목록을 함께 전달). 예시는 "작업 완료"
- `>`의 등장 연출(페이드 여부 · 길이), 아이콘 회전과 펼침 모션, 펼친 내용의 구성
- 이동 시간 240ms와 완료 문구 색(라이트 `#1C1C1E` · 다크 `#B8B8BD`)은 원본에서 임시. 완료 문구의 투명도 0 → 100%도 임시
- 이전 답변의 완료 문구 · 아코디언은 그대로 남기고 새 질문은 새 작업 상태 줄에서 시작한다는 처리(원본 미정)
- Android · iOS 구현
