# Signature

AI Agent를 처음 만나는 순간에 한 번 재생되는 시그니처 모션입니다. 화면 구조와 표시 크기는 [4-9. AI 심볼 · 모션](../4-9-symbol.md)에 있습니다.

- 상태: 초안. 인사말 문구와 요소는 미정
- 규칙: [2-2 심볼](../../2-rules/2-2-ui.md#심볼-ui-sym) UI-SYM-01 ~ 02, UI-SYM-12 ~ 14

## 구조

| 요소 | 클래스 | 역할 |
| --- | --- | --- |
| 시그니처 심볼 | `.symbol.is-landing` | `agent_signature` 슬롯. 흩어진 원 세 개가 모여 하나의 AI가 깨어남 |
| 인사말 | 미정 | 심볼 아래에 놓는 문구(예: "무엇이든 물어보세요", "○○님 도와드릴까요?"). 텍스트 시머 금지 |

## 배치

| 요소 | 기준 | 위치 · 정렬 |
| --- | --- | --- |
| 시그니처 심볼 | 콘텐츠 패널 | 가로 · 세로 가운데 |
| 인사말 | 시그니처 심볼 | 심볼 아래 |

- 쓰는 곳: 앱 첫 실행 후 첫 화면, 온보딩 시작 화면, 세션의 첫 메인 진입
- 쓰지 않는 곳: 대화 중 작업 상태 줄, 로딩 · 대기 표시, 같은 세션에서 메인으로 돌아올 때, 카드 · 패널 · 헤더 같은 작은 영역

## 크기

| 요소 | 속성 | 값 | 비고 |
| --- | --- | --- | --- |
| 시그니처 심볼 | 표시 크기 | 심볼 48 × 48 | 뷰 약 81 × 81. Mobile · Desktop 공통. 원본의 Mobile 44(뷰 74) · Desktop 56(뷰 95)은 따르지 않음([4-9](../4-9-symbol.md)) |
| 시그니처 심볼 | 캔버스 | 600 × 600 | 원이 퍼질 여백 포함. 완성 심볼 영역 355 × 353 |

시그니처는 큰 크기에서만 씁니다. 뷰가 100을 넘으면 600px 리소스로 바꿔야 합니다([적용 코드](code.md)).

## 상태

| 상태 | 언제 | 바뀌는 것 |
| --- | --- | --- |
| 재생 | 세션 첫 메인 진입 · 온보딩 시작 | 0프레임(빈 캔버스)에서 시작. 별도 등장 연출 없음 |
| 정지 | 재생 완료 | 66프레임(완성 심볼)에서 멈춰 정지 심볼로 유지. 되감거나 사라지지 않음 |
| 재진입 | 같은 세션에서 첫 화면으로 돌아옴 | 정지 심볼로 보임. 다시 재생하지 않음 |
| 대화 시작 | 사용자가 요청 전송 | 입력을 막지 않음. 메인 심볼 영역이 화면 전환과 함께 200ms 페이드 아웃, 대화 작업 상태 줄에서 Thinking 시작 |
| 화면 이탈 | 재생 중 다른 화면으로 이동 | 즉시 정지. 퇴장 연출 없음. 돌아와도 재생하지 않음 |

## 동작

`agent_signature`는 2.01초 · 67프레임 · 33.33fps(프레임당 30ms)이고 1회 재생 후 마지막 프레임을 유지합니다. 회전은 시계 방향입니다.

| 구간 | 시간 | 프레임 | 형태 변화 |
| --- | --- | --- | --- |
| 빈 화면 | 0.00 ~ 0.06초 | 0 ~ 1 | 아무것도 보이지 않음 |
| 등장 | 0.06 ~ 0.45초 | 2 ~ 14 | 원 세 개가 0.035초 간격으로 나타나 시계 방향으로 돌며 퍼짐 |
| 모임 | 0.45 ~ 0.80초 | 15 ~ 26 | 돌면서 커지다 감속하며 모임. 가까워질수록 끈적하게 붙음 |
| 열림 | 0.80 ~ 1.10초 | 27 ~ 36 | 가운데에 점 같은 구멍이 생겨 둥글게 열리고 심볼 형태가 됨. 가운데 하이라이트가 구멍과 함께 생김 |
| 안착 | 1.10 ~ 2.01초 | 37 ~ 66 | 아주 작은 반동만 남기고 원본 심볼 방향 · 색으로 멈춤 |

1. 첫 진입(세션 첫 메인) → 0프레임부터 1회 재생
2. 재생 완료 → 마지막 프레임 유지(정지 심볼)
3. 인사말 → 안착 구간(1.10초 이후)에 200ms 페이드 인
4. 색(시안 → 바이올렛 → 핑크)은 형태와 함께 흐르고 끝에서 원본 심볼 색 방향으로 고정. 심볼 내부 빛 흐름과 모션 블러는 리소스에 포함되어 있어 별도 레이어를 더하지 않음
5. 세션 1회 판단은 앱이 맡음. 재생 후 플래그를 저장
6. 반복 재생, 로딩 · 대기 표시 대용, 화면 페이드 · 확대 · 외곽 글로우 · 빛 줄기 같은 추가 연출은 하지 않음

## 에셋

| 파일 | 형식 | 경로 |
| --- | --- | --- |
| `agent_signature` | Lottie JSON | [assets/symbol/resources/motion/agent_signature/lottie/](../../assets/symbol/resources/motion/agent_signature/lottie/agent_signature.json) |

플랫폼별 구현: iOS는 lottie-ios(`loopMode = .playOnce`), Android는 lottie-android(`repeatCount = 0` · `playSignature()`), 웹은 lottie-web svg(`loop: false`), React Native는 lottie-react-native(`loop={false}`). 대체 형식과 용량은 [적용 코드](code.md)에 있습니다. 재생 완료는 `complete` 이벤트로 판단합니다.

## 참고

- 움직임 줄이기(`prefers-reduced-motion: reduce`)가 켜지면 재생하지 않고 정지 심볼만 보임(UI-SYM-08)
- 심볼은 스크린리더에서 장식으로 숨기고 인사말을 읽음(UI-SYM-25)
- 재생 중에도 입력 · 스크롤을 막지 않음(UI-SYM-26)

## 미정

- 인사말 문구. "무엇이든 물어보세요"는 임시 문구
