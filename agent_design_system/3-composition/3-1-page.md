# 3-1. 화면

채팅 화면 전체를 어떻게 나누고, 화면 폭에 따라 콘텐츠를 어떻게 배치하는지 정합니다. 화면 안의 대화는 [3-2. 턴](3-2-turn.md)에서 다룹니다.

## 구조

```
화면       = 헤더 + 콘텐츠 패널 + 입력창
콘텐츠 패널 = 대화                      ← 3-2. 턴
```

| 요소 | 클래스 | 역할 |
| --- | --- | --- |
| 화면 | `.chat` | 채팅 영역 바깥 래퍼 |
| 헤더 | — | 화면 맨 위 영역. 스펙 범위 밖 |
| LNB | — | 화면 왼쪽 메뉴. 스펙 범위 밖 |
| 콘텐츠 패널 | `.markdown` | 대화가 놓이는 영역 |
| 대화 | `.thread` | 턴을 세로로 쌓는 영역([3-2. 턴](3-2-turn.md)) |
| 첫 진입 빈 화면 | `.landing` | 대화가 없을 때 패널 가운데 심볼을 보여 주는 영역 |
| 입력창 | `.composer` | 화면 맨 아래 입력 영역([4-7. 입력창](../4-resources/4-7-input.md)) |

## 배치

| 요소 | 기준 | 위치 · 정렬 |
| --- | --- | --- |
| 헤더 | 화면 | 맨 위 |
| 콘텐츠 패널 | 헤더와 입력창 사이 | 위에서 아래로만 쌓임. 새 메시지는 항상 맨 아래에 붙음 |
| 입력창 | 화면 | 맨 아래 |
| LNB | 화면 | 왼쪽 |
| 대화 | 콘텐츠 패널 | Mobile · Tablet은 패널 폭에 맞춰 늘어남(Fluid), Desktop은 가운데 정렬 고정 폭(Fixed). 값은 `## 반응형` |
| 첫 진입 심볼 | 콘텐츠 패널 | 세로 가운데 |

## 크기

| 요소 | 속성 | 값 | 비고 |
| --- | --- | --- | --- |
| 첫 진입 심볼 | 폭 × 높이 | 48 × 48 | [4-9. AI 심볼 · 모션](../4-resources/4-9-symbol.md)을 따름 |
| LNB | 폭 | 260 | 스펙 범위 밖 |

## 간격

| 사이 | 값 | 비고 |
| --- | --- | --- |
| 콘텐츠 패널 위 → 첫 턴 | 40 | |
| 마지막 턴 → 콘텐츠 패널 아래 | 60 | |

## 상태

| 상태 | 언제 | 바뀌는 것 |
| --- | --- | --- |
| 첫 진입 | 대화가 없을 때 | 콘텐츠 패널 세로 가운데에 시그니처 심볼 · 인사말 · 입력창 묶음을 놓고 시그니처를 1회 재생. 위 40 · 아래 60 간격은 두지 않고 패널 전체의 가운데에 놓음([4-9](../4-resources/4-9-symbol.md)) |
| 대화 | 첫 메시지를 보낸 뒤 | 빈 화면이 대화로 바뀌고 턴이 쌓임 |

## 동작

1. 첫 메시지를 보냄 → 빈 화면이 대화로 바뀐다
2. 새 메시지가 생김 → 콘텐츠 패널 맨 아래에 붙는다

## 반응형

화면 폭 구분의 정본은 이 표입니다. 브레이크포인트는 **화면(뷰포트) 폭** 기준입니다.

| 요소 | Mobile | Tablet | Desktop |
| --- | --- | --- | --- |
| 화면 폭 | 0 ~ 767 | 768 ~ 1023 | 1024 ~ |
| 유형 | Fluid | Fluid | Fixed |
| 콘텐츠 폭 | 패널 폭 − 40 | 패널 폭 − 64 | 720 (가운데 정렬) |
| 좌우 마진 | 20 | 32 | auto (최소 32) |

```
Mobile 402            Tablet 768                      Desktop 1280
┌───────────┐         ┌─────┬──────────────┐          ┌─────┬─────────────────────────┐
│20│ 362 │20│         │ LNB │32│  444   │32│          │ LNB │auto│     720     │auto│
└───────────┘         │ 260 │              │          │ 260 │                         │
                      └─────┴──────────────┘          └─────┴─────────────────────────┘
```

Tablet에서 LNB가 있으면 패널 폭은 768 − 260 = 508, 콘텐츠 폭은 444입니다. 좌우 마진은 [4-8. HTML 구조 · 고정 CSS](../4-resources/4-8-markup.md)의 고정 CSS에 있습니다.

## 참고

- 헤더와 LNB는 이 스펙의 범위가 아닙니다. 채팅 컴포넌트는 콘텐츠 패널과 [4-7. 입력창](../4-resources/4-7-input.md)을 그립니다.

## 스타일

> 표 읽는 법은 [4-1. 디자인 토큰](../4-resources/4-1-tokens.md)의 "스타일 표 읽는 법"을 보세요.

| `&` | `background` | `{color/frame/base/high}` | color/frame/base/high |
| `.thread` | `max-width` | `720px` | |
| `.thread` | `padding-top` | `40px` | spacing/layout/y/40 |
| `.thread` | `padding-bottom` | `60px` | |

## 미정

- `## 스타일` 표에 `.chat`의 `background`가 `.chat` 행과 `&` 행으로 두 번 적혀 있음. 같은 값이라 화면 차이는 없으나 한 행으로 줄일지 정해야 함
