# 프로필 양식 안내

문서 종류에 맞는 양식을 복사해 씁니다. 종류와 강도는 [chat-ui 프로필](../chat-ui-profile.md)의 "문서 틀"을 따릅니다. 일반 문서와 규칙 문서 양식은 [core 양식](../../core/templates/index.md)에 있습니다.

| 문서 | 대상 | 역할 |
| --- | --- | --- |
| [component.md](component.md) | 구성 · 컴포넌트 | H2 항목 전체가 들어 있는 뼈대. 필요 없는 항목은 지움 |
| [resource.md](resource.md) | 리소스(`symbol/`의 모션 문서) | 리소스 문서 뼈대 |
| [demo.md](demo.md) | 시연 · 시나리오 | 대화 파일 뼈대. 시나리오는 `type: example`, `id: CV-NN`으로 바꿈 |
