# 공통 점검 항목 (core)

표준은 [doc-standard.md](doc-standard.md)입니다. 필수와 권장 항목은 검증 스크립트가 잡고, "사람이 확인" 항목은 사람이 봅니다.

## 필수

- [ ] frontmatter 필수 키와 값 범위
- [ ] `id`가 전체에서 유일하고, `refs`의 ID가 모두 정의되어 있음
- [ ] 상대 링크가 모두 실제 파일을 가리킴
- [ ] 모든 문서가 `INDEX.md`나 하위 `index.md`에 등록되어 있음
- [ ] H1이 `title`과 같음

## 권장

- [ ] H1 바로 뒤에 도입 문장이 있음
- [ ] 섹션이 프로필의 문서 틀을 따름
- [ ] 규칙 표에 ID, 강도, 규칙, 근거가 있음
- [ ] 용어집의 "쓰는 말"을 씀
- [ ] `## 미정`이 문서 맨 끝에 있음

## 사람이 확인

- [ ] `summary`가 문서 내용을 한 문장으로 정확히 말함
- [ ] 같은 내용을 두 곳에서 정의하지 않음
- [ ] 폐기한 ID를 다시 쓰지 않음
- [ ] 버전을 올렸으면 `CHANGELOG.md`에 적음
