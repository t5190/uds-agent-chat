Claude Code에 스킬로 한 번 설치해 두면, 말로 시키는 것만으로 채팅 화면 HTML이 만들어집니다. 스킬은 정해진 클래스와 값만 쓰고, 정의에 없는 요소는 만들지 않고 "미정"이라고 알려 줍니다.

1. 폴더 받기

zip을 풀거나 저장소를 받아 uds-chat-build 폴더를 준비합니다. 위치는 어디든 괜찮습니다.

2. 설치하기

Claude Code를 열고 말합니다. 설치가 끝나면 Claude Code를 닫았다가 다시 엽니다.

uds-chat-build 폴더를 스킬로 설치해줘

3. 화면 만들기

/uds-chat-build 뒤에 만들고 싶은 화면을 말합니다. 이렇게 말해 보세요.

만들고 싶은 것이렇게 말하기
처음 만들어 보기/uds-chat-build 영화 예매 대화 화면을 만들어줘
첫 진입 화면/uds-chat-build 인사말과 입력창이 있는 첫 진입 화면을 만들어줘
파일이 오가는 대화/uds-chat-build 견적서 PDF를 첨부하고 비교표와 결과 파일이 나오는 대화를 만들어줘
이미지가 있는 대화/uds-chat-build 이미지 4장을 첨부한 요청과 AI 답변을 만들어줘
출처가 있는 답변/uds-chat-build 월세 시세 리서치 답변을 만들어줘. 작업 상태 줄, 출처 칩, 출처 목록을 넣어줘
진행 중인 상태/uds-chat-build 도구 사용 줄과 작업 목록이 보이는 진행 중 화면을 만들어줘
다크 모드/uds-chat-build 위 화면을 다크 모드 시안으로도 만들어줘

4. 확인하기

작업이 끝나면 브라우저가 저절로 열립니다. 파일은 프로젝트의 uds-chat 폴더에 저장됩니다.

  • uds-chat/<이름>.html: 만들어진 화면
  • uds-chat/assets/: 화면이 쓰는 CSS, 서체, 심볼 모션
  • uds-chat/serve.mjs: 화면을 띄우는 서버. node uds-chat/serve.mjs

5. 개발자에게 넘기기

uds-chat 폴더를 폴더째 전달합니다. HTML만 보내면 CSS와 서체, 심볼 모션이 빠져 화면이 깨집니다.

줄 것받는 사람이 하는 일
uds-chat/ 폴더 전체node uds-chat/serve.mjs로 띄워 화면을 바로 확인한다
<이름>.html대화 부분이 정적 마크업이라 구조와 클래스를 그대로 가져다 쓴다
assets/design-system.css화면의 모든 스타일. 클래스 이름은 정해진 것만 쓴다
assets/의 서체 · 모션 · 스크립트심볼 모션과 순서대로 나타나는 연출에 쓴다

구조와 클래스 정의는 agent_design_system/4-resources/4-8-markup.md에 있습니다. 같이 전달하면 받는 사람이 정의에 없는 값을 쓰지 않도록 확인할 수 있습니다.

Chat.html

스펙(md)을 읽어 채팅 화면을 그리는 미리보기입니다. 스펙을 고치는 사람과 검토하는 사람이 씁니다. 종류별로 묶인 시연 케이스를 넘겨 보고, 직접 대화를 써 보고, 지금 보이는 화면을 코드로 내보낼 수 있습니다. 스킬로 화면을 만들 때는 필요 없습니다.

열기

폴더에서 서버를 띄우고 주소를 엽니다. file://로 열면 스펙을 읽지 못해 그리지 않습니다.

bash
npm run dev
# 열기: http://127.0.0.1:8765/chat.html

터미널에서 실행하는 것이 가장 확실하지만, Claude Code 같은 AI 창에서 npm run dev 실행해줘라고 말해도 됩니다. AI가 서버를 띄우고 주소를 알려 줍니다.

서버 없이 열고 싶으면 npm run build 뒤 dist/chat.html을 엽니다.

코드로 내보내기

화면 위쪽 내보내기를 누르면 지금 보이는 대화를 코드로 가져갈 수 있습니다.

메뉴결과
HTML 파일 저장파일 하나로 바로 열립니다. CSS와 심볼 모션이 안에 들어 있고, 서체는 Pretendard CDN입니다
HTML 전체 복사같은 내용을 클립보드로 복사합니다
마크업만 복사대화 부분의 HTML만 복사합니다. 내 프로젝트 CSS와 모션에 연결할 때 씁니다

내보낸 파일에서 "전체보기", "더보기", 출처 호버 같은 조작은 동작하지 않고 보이는 모양만 담깁니다.

스펙을 고친 뒤

bash
npm run build   # 스타일 표나 2-1을 고쳤을 때 먼저
npm run check   # 오류 0건이어야 합니다

문제가 생겼을 때

증상해결
Chat.html이 비어 있고 안내 문구만 나온다file://로 열었습니다. npm run dev로 띄운 주소로 엽니다
npm run dev가 "address already in use"로 멈춘다이미 떠 있는 서버를 쓰거나 PORT=8766 npm run dev로 다른 포트를 씁니다
스펙을 고쳤는데 화면이 그대로다새로고침을 누릅니다. 스타일 표를 고쳤다면 npm run build도 먼저 합니다
만든 화면의 폰트나 심볼이 안 나온다file://가 아니라 node uds-chat/serve.mjs 주소로 엽니다
내보낸 HTML의 글꼴이 다르다서체를 Pretendard CDN에서 받습니다. 인터넷이 막힌 곳에서는 기본 글꼴로 보입니다
npm run check가 오류를 낸다메시지의 파일과 규칙 번호를 보고 고칩니다. 점검표는 standard/에 있습니다
